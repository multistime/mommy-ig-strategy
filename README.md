# Instagram Growth Playbook — mommy.by

Стратегический плейбук для роста Instagram **@dr.ladutko_v** (Вероника Ладутько, педиатр и консультант по ГВ/прикорму) и конверсии в консультации на **mommy.by**. Горизонт дорожной карты на сайте: **до 31.05.2026 включительно**; целевой ориентир — **1000 целевых подписчиков** (KPI уточняются по Insights).

Плейбук собран с участием трёх ролей: **SMM** (ритм, рубрики, A/B), **PR** (красные линии, коллабы, модерация), **медиавoice** (тон, дисклеймеры, CTA под форматы 80 / 170 / 230 BYN).
