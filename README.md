# Instagram Growth Playbook — mommy.by

Стратегический плейбук для роста Instagram-аккаунта педиатра и консультанта по ГВ/прикорму **Вероники Ладутько** до 1000 целевых подписчиков за 8–12 недель.

## Что внутри

- Упаковка профиля: варианты био, highlights, закрепы, welcome в Директ
- Контент-банк из 30 тем по 5 столпам
- Недельный контент-календарь и производственный SOP
- 15 партнёров для коллабораций + скрипты сообщений
- Лид-магнит «Старт прикорма: 7 шагов» + воронка Instagram → mommy.by
- Система еженедельной аналитики и корректировки
- 12-недельный спринт с этапами и задачами
